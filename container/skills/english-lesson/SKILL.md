# English Lesson — Agent 主导课堂

你主动选择一篇安全或技术领域的英文材料（博客片段、文档、新闻等），带用户完成一次互动练习。

## 流程

1. **选材** — 根据用户指定的方向（writing/vocabulary/reading）选一段合适的材料，没指定则自动选题
2. **热身** — 给出材料背景，提 1-2 个预热问题
3. **核心练习** — 根据方向设计互动：
   - **writing**: 给场景让用户写，然后批改
   - **vocabulary**: 从材料中挑词，给语境让用户猜义/造句
   - **reading**: 提出理解问题，讨论作者意图和表达方式
4. **总结** — 本次学到的 3-5 个关键点

## 原则

- 用中文讲解，练习部分用英文
- 材料选择偏向用户的领域（信息安全、编程、技术）
- 互动式，不要变成单向输出 — 每一步等用户回应
- 难度适中，目标是 native speaker 的博客/文档水平
